## 🏛️ 5-Layer Defense-in-Depth Architecture

1. **`Layer 1: Perimeter Shield`**  
   Ingress protection: Intercepts direct prompt injections, jailbreaks, and perimeter credential probes in `<10ms` (0 tokens consumed).
2. **`Layer 2: PII Gateway`**  
   Privacy gateway: Redacts client Social Security Numbers, phone numbers, and emails to `[REDACTED]` tokens on-the-fly.
3. **`Layer 3: Core Reasoning Engine`**  
   Cognitive agent core: Multi-step ReAct reasoning on Groq LPU, live market data lookups, and dual anti-hallucination verification (audited SEC 10-K facts vs. ungrounded fabrication refusal).
4. **`Layer 4: Code Execution Sandbox`**  
   Runtime execution safety: Deterministic Python financial calculations; blocks host OS command injections, file system traversal, and outbound network socket egress.
5. **`Layer 5: Policy & Compliance Shield`**  
   Enterprise governance & statutory audit: Halts illegal securities practices including Insider Trading (SEC Rule 10b-5), Market Manipulation (Pump & Dump), and strips prohibited profit guarantees (FINRA Rule 2210 / SEC Rule 156).

## 🏷️ Standard Action Status Definitions

* **`PASSED`** (🟢 Green): The query is benign, factual, and completed through the full agent pipeline.
* **`BLOCKED`** (🔴 Red): The adversarial injection, unauthorized code, or policy violation was halted by the enforcing layer.
* **`MASKED`** (🟡 Yellow): Confidential personal data (SSN, Email) was redacted to `[REDACTED]` before model inference.
* **`REMEDIATED`** (🟠 Orange): Prohibited certainty promises were stripped and statutory FINRA/SEC disclaimers appended.
